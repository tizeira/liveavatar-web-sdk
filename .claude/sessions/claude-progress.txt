### Part 2 — Chroma Key / Green Screen Feature (uncommitted)

Added configurable green screen removal via Canvas 2D chroma keying.
Controlled by `CHROMA_KEY_ENABLED` env var (set per-environment in Vercel).

**New files:**
- `src/hooks/useChromaKey.ts` — HSV-based chroma key hook (matches HeyGen official bg-removal-demo)

**Modified files:**
- `app/api/secrets.ts` — `CHROMA_KEY_ENABLED`, `*_GREENSCREEN` avatar ID selection
- `app/api/start-custom-session/route.ts` — passes `chroma_key_enabled` to frontend
- `src/components/ClaraVoiceAgent.tsx` — AvatarVideo with 3-layer DOM stack (bg/video/canvas)
- `src/hooks/index.ts` — exports useChromaKey
- `turbo.json` — new env vars in globalEnv

**How it works:**
- `CHROMA_KEY_ENABLED=false` (default): normal avatar with background, plain <video>
- `CHROMA_KEY_ENABLED=true`: green screen avatar + canvas chroma key processing
- Algorithm: RGB→HSV conversion, hue range 60°-180°, greenness soft-edge formula
- DOM: bg-layer(z-0) → video(z-10, visibility:hidden) → canvas(z-20)
- video uses `visibility:hidden` (NOT opacity:0) to keep decoder active

**Vercel env vars (Preview only):**
- `CHROMA_KEY_ENABLED=true`
- `HEYGEN_AVATAR_ID_DESKTOP_GREENSCREEN=<avatar-id>`
- `HEYGEN_AVATAR_ID_MOBILE_GREENSCREEN=<avatar-id>`
